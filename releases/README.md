# Rilis DompetKu (APK)

Unduh file `.apk` di folder ini langsung dari GitHub, pindahkan ke HP Android,
lalu install.

| File | Versi | Keterangan |
| ---- | ----- | ---------- |
| `dompetku-v1.0.0.apk` | 1.0.0 (versionCode 1) | Rilis pertama, release build signed |

## Cara install di HP

1. Download APK-nya (tombol Download di halaman file GitHub).
2. Buka file-nya di HP → izinkan "Install dari sumber tidak dikenal" jika diminta.
3. Buka aplikasi DompetKu → setujui izin **SMS** agar pencatatan otomatis jalan.
4. Pastikan HP terkoneksi internet saat SMS transaksi masuk.

Catatan: update berikutnya harus ditandatangani dengan kunci yang sama agar
bisa menimpa instalasi lama tanpa uninstall.
