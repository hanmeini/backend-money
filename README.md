# DompetKu

Monorepo untuk aplikasi **DompetKu** — pengelola keuangan otomatis berbasis SMS e-wallet.

## Isi

| Folder | Deskripsi |
| ------ | --------- |
| [`backend/`](./backend) | API server (Node.js + Fastify + Prisma + MySQL) |
| `app/` | Aplikasi Android (Expo Development Build) |

## Backend

Lihat [`backend/README.md`](./backend/README.md).

Domain: `https://dompetku.hanmeini.my.id`

## App

Aplikasi Expo yang menangkap SMS transaksi e-wallet dan mengirimkannya ke backend.
